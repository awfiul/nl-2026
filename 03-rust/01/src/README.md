# Примеры кода к презентациям про Rust

Каждый файл — самостоятельная программа (`fn main() { ... }`), проверена компиляцией и запуском (rustc 1.75, edition 2021).

| Файл | К какому слайду |
|---|---|
| 01_variables.rs | Переменные: имя, значение и память |
| 02_types_and_scope.rs | Типы данных и область видимости |
| 03_type_conversion.rs | Явное преобразование типов |
| 04_control_flow.rs | Условия и циклы (if/else, loop, while, for) |
| 05_functions_recursion.rs | Функции и рекурсия |
| 06_error_handling.rs | Обработка ошибок (panic!, assert!, assert_eq!) |
| 07_full_program.rs | Маленькая программа целиком |
| 08_ownership_move.rs | Ownership: как Rust управляет значениями |
| 09_ownership_drop_raii.rs | Ownership ≈ RAII (кастомный Drop) |
| 10_bonus_pattern_matching_option.rs | Бонус: Pattern matching + Option (слайд 7, без кода в презентации) |
| 11_bonus_traits.rs | Бонус: Traits (слайды 6–7, без кода в презентации) |
| 12_bonus_borrowing.rs | Бонус: Borrowing, &T / &mut T (заметка к слайду 9) |

Запуск любого файла:
```
rustc --edition 2021 01_variables.rs -o 01_variables.exe
.\01_variables.exe
```

Во всех файлах закомментированные «неправильные» варианты (мутация неизменяемой переменной, использование после move, неявное сложение i32+f64, выход переменной за пределы области видимости) — реально проверены: без раскомментирования компилируются и работают, с раскомментированием — не компилируются с тем сообщением об ошибке, которое имелось в виду на слайде.
